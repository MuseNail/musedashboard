C8 — Turns board on a BUSY day (10 techs) — readable AND no scrolling

The frame below is sized like your iPad's usable height for the tech list (~520px). Flip between today's sizes and the proposed bump. The row height grows only ~4px per tech — all 10 still fit.

Proposed: tech name 14px (was 13), bubble service 13px (was 12), time/price meta 12px (was 9–10). Empty turn slots compress to small "+" chips so busy rows get the space. If the salon ever grows past ~12 techs, rows switch to a 2-column grid before anything scrolls.

D13 — Filters should not look like statuses

Today both are grey rounded chips. Proposed: filters = outlined, with a ✓ when active (they're buttons you press) · statuses = color-filled pills (they're labels you read — using the filled style you said you prefer).

Same vocabulary everywhere (C9): Waiting · In Service · Done · Paid — no more "In Svc" / "Complete" variants. Colors: amber = waiting, teal = in service, green = done, slate = paid.

E6 — Price fields that look tappable

Today a price field looks like a plain text input — nothing says "tap me for the keypad." Proposed: a keypad glyph inside the field. Same behavior, just visible.

A3 — Global search: how it looks & works

How you reach it: a magnifier icon in the header (next to the sync pill), or just start typing… it opens an overlay like this. Type in the box below — try "co", "951", or "2207".

search

How it works: searches as you type (2+ characters), everything is instant because it reads the data already in the app — no network call. Phone digits match any part of the number. Tapping a result takes you straight to the right place:

WhatMatched byTap →
✓ Customers (directory)name, phoneopens the customer editor (notes, history)
✓ Today's queue ticketsguest name, phoneopens that ticket's Assign & Price
✓ Recent transactions (90 days)customer nameopens the transaction card in Sales
✓ Gift cardsserial #, recipient nameopens the gift card in Sales → Gift Cards
✓ Today's appointmentsguest name, phoneopens the appointment popup (Quick Check-In etc.)
✗ Older calendar eventsonly TODAY's appointments are loaded in the app; searching past/future weeks would need Google round-trips — out of scope
✗ Reports / payroll numbersaggregates, not records — use the Reports tab
✗ Settings, staff, chat messagesnot customer-facing lookups; excluded to keep results clean
✗ Archived turns historydevice-local archive; not indexed

Permissions: transactions only appear for roles that can already see the Sales tab. Customers/queue/appointments appear for everyone — that's the front-desk use case.
